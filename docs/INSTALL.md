# 轻启 1.2.0 安装说明

已有桌面整合助手的用户只需下载 `quietstart-1.2.0.hap`。首次使用可下载对应电脑的完整整合包；Mac 选 Apple 芯片版，Windows 选 x64 版。整合包沿用原有桌面助手，仅更新轻启本体和必要的版本说明、校验信息。

## 电脑安装或升级

1. 解压整个整合包。Windows 保留 EXE 旁的 DLL 和 data 目录；Mac 可将 APP 移到“应用程序”。
2. 手机开启开发者模式和 USB 调试，用 USB 连接电脑并允许调试授权。
3. 打开整合助手，登录自己的华为开发者账号，选择 `quietstart-1.2.0.hap`，核对显示版本为 1.2.0。
4. 点击“开始调试”，由助手为手机重签轻启主包和内嵌工作模块，等待安装完成。需要同时重签内外两层。
5. 打开轻启，按向导开启无线调试、填写当前端口并允许本机连接。概览显示在线后检查后台保护状态。
6. 在“工具包”中导入并启用需要的兼容工具包，在“应用”中开启对应应用。本项目不随正式版提供具体工具包附件。

轻启默认使用计算任务后台保护；这条路径无需定位权限。计算任务能否获授权由手机系统和重签材料决定。

## 独立手机安装器附件

独立附件为自研的 `quietstart-installer-0.4.46-device6.1-signed.hap`，与 [本仓库 1.2.0 Release](https://github.com/thx853068675-dev/quietstart/releases/download/v1.2.0/quietstart-installer-0.4.46-device6.1-signed.hap) 发布的文件一致。直接在手机侧载安装器，打开后选择轻启，一键完成安装。

安装器使用与旧版 0.4.36 相同的 AGC 调试 Profile，仅适用于该 Profile 已授权的设备。其他设备需要正式发布签名版本。0.4.46 已对轻启主包和内嵌工作模块分别重签。

安装完成后打开轻启，按向导完成本机连接，并确认概览显示“在线”。原“小白·轻启”已弃用。

## 本版使用变化

- 示范学习需要工具包声明相应能力；已有 V4 工具包的普通识别可继续使用，页面布局示范需要 V5 或更新的兼容包。示范生成的有效规则可在应用自动执行列表查看和管理。
- 新规则自动启用默认开启；已有明确停用设置会保留。仍需用户确认的规则不会因此自动执行。
- 隐藏后台默认关闭。隐藏多任务卡片不能保证绕过系统一键清理；需要时保留卡片并使用系统提供的加锁方式。
- 普通纯绘制页面默认不做无广告线索的探索性截图 OCR。应用详情可以关闭该应用全部截图 OCR，也可以按需开启“探索纯绘制页面”。关闭 OCR 会减少截图分享干扰，同时限制图片文字识别；开启探索仍可能触发应用的截图分享。
- 可添加 2×2 桌面状态卡片，查看连接状态与执行指标。

## 升级与校验

同一有效签名下覆盖安装通常保留规则、工具包和设置。提示签名不一致时应检查签名材料，卸载会删除应用数据。本版内部版本码为 120000，高于 1.1.0 和 1.1.1-beta。

下载后核对 `SHA256SUMS.txt`。两平台整合包内的轻启 HAP 与独立 HAP 相同，桌面助手没有重新编译。桌面助手的原项目：<https://github.com/likuai2010/auto-installer>；整合版由轻启维护者修改，不是小白官方版。
