# 使用说明

## 安装和连接

首次安装请完整阅读 [侧载安装指南](INSTALL.md)。只侧载轻启主包，工作模块由轻启在首次本机连接时自动安装。

已安装后恢复会话：开启无线调试 → 查看当前端口 → “概览 → 本机连接”填写并授权 → 等待“在线”。重连无需删除规则，也不需要电脑持续连接。

## 发现并启用规则

保持“自动发现应用”和“学习新规则”开启，正常打开其他应用。轻启在启动观察窗口内收集候选；回到规则页查看按钮文字及位置，确认后启用，并确认应用与自动跳过开关也已打开。

已有规则不阻止学习其他样式。新样式不会因旧规则启用而自动获得批准。一个应用的多条规则聚合展示，可左右切换。需要重学时使用“重新学习”，它会删除该应用旧规则和审批状态。

## 页面分工

- **概览**：在线状态、自动跳过开关、连接入口、会话详情与运行记录。
- **应用**：查看已遇到的应用，暂停或恢复检测、修改备注、管理规则。
- **规则**：查看待确认和全部规则，启用、停用或重新学习。
- **设置**：识别策略、学习及自动发现、无广告暂停参数、通知和主题。

运行记录每个过程一张卡片，眼睛入口展开时间线。尝试点击、观察到消失、未能确认是不同结果；请结合过程详情判断。

## 未见广告时自动暂停

默认观察跨度 1 天、完成检查 3 次、7 天后复查，均可调整。正常情况下连续有效检查约 6 秒，信息不稳时最多观察 12 秒。未完成、存在广告线索或重复检查不会直接计为“无广告”。

达到时间和次数门槛后仍需有效检查确认，不会仅靠时间流逝移入暂停。自动暂停只表示暂未发现广告，可手动恢复；不承诺应用永远无广告。

## 常见问题

- **连接失败**：确认安装的是完整单包版本、无线调试开启、端口为当前值，并处理系统授权。
- **升级后离线**：通过本机连接重新激活；不需要删除规则。
- **按钮未点击**：检查规则审批、应用及总开关；展开该过程日志查看具体拒绝原因。
- **应用仍显示包名**：系统或卓易通可能不提供完整名称，可手动备注；图标截图采集已移除。
- **没有学到规则**：页面信息、结构或广告依据不足时会拒绝；不要把任意关闭按钮都认作广告。
- **提醒未出现**：检查系统通知权限和轻启提醒设置。当前使用普通累计通知，不保证系统胶囊形态。
