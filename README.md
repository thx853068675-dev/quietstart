## 下载与安装

请从 [Releases](https://github.com/thx853068675-dev/quietstart/releases) 下载最新版：

- **首次安装**：选择对应平台的整合包。
- **已经安装整合助手**：可单独下载 HAP。
- 安装前请核对 Release 中提供的 SHA-256 校验值。

HarmonyOS 应用的侧载签名与设备绑定；请使用整合助手为自己的设备完成签名和安装。
