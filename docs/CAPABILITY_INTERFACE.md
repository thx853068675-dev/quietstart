# 工具包能力接口字段手册

> 按轻启 `1.2.1-beta`（120312）核对的 JSON 工具包接口。公开正式版 1.2.0 可使用 `schema: 1/2`；`schema: 3`、`entryAfterClick`、`repeat.stopWhen`、`steps[].skipWhen` 从 1.2.1-beta（120311）开始提供。本文描述配置接口，实际动作仍受应用开关、规则确认、前台归属与轻启内置校验约束。

从 [制作教程](TOOL_PACKS.md) 开始写第一份包；本文用于查字段、取值、默认值和组合限制。`.task.json` 是 UTF-8 JSON，不能写注释、尾逗号或重复键。未列出的字段会使整份配置被拒绝。除特别说明，字段区分大小写。

## 1. 格式、版本与作用范围

| 格式 | 用途 | 顶层必填字段 | 兼容性 |
|---|---|---|---|
| `schema: 1` | 旧式可读包，供已有包导入 | 沿用旧格式 | 正式版 1.2.0 及以后 |
| `schema: 2` | 一份独立任务 | `schema`、`id`、`name`、`version`、`when`、`steps` | 正式版 1.2.0 及以后；新增字段另见下文 |
| `schema: 3` | 一份分发文件包含 1–8 个任务，一个开关 | `schema`、`id`、`name`、`version`、`appliesTo`、`entryAfterClick`、`tasks` | 1.2.1-beta（120311）及以后 |

### schema 2 顶层

| 字段 | 类型与范围 | 作用 |
|---|---|---|
| `schema` | 固定整数 `2` | 选择单任务格式。 |
| `id` | 非空字符串，最长 64 字符 | 稳定身份。再次导入同一 ID 更新内容。 |
| `name` | 非空字符串，最长 40 字符 | 工具包列表中的名称。 |
| `version` | 整数 ≥ 1 | 作者递增的内容版本。 |
| `priority` | 可选整数 100–1000，默认 500 | 数字越小，候选优先级越高。 |
| `appliesTo` | 可选包名数组，最多 16 项 | 精确限定适用应用；不写或空数组表示不额外限定。 |
| `manual` | 可选对象 | 主动示范入口，见第 10 节。 |
| `when` | 必填对象 | 触发时机，见第 2 节。 |
| `defaults` | 可选对象 | 步骤共用的几何与复核默认值，见第 3 节。 |
| `repeat` | 可选对象 | 多步流程的有界重复，见第 8 节。 |
| `steps` | 1–8 项数组 | 顺序执行的步骤，见第 4 节。 |

`appliesTo` 的每个包名最长 128 字符、至少两段并用句点分隔；首段以英文字母开头，其余字符限英文字母、数字、下划线。数组不得重复。写了 `appliesTo` 只会收窄范围；轻启内的逐应用开关和已确认规则仍必须满足。

### schema 3 顶层

| 字段 | 类型与范围 | 作用 |
|---|---|---|
| `schema` | 固定整数 `3` | 选择合成包格式。 |
| `id` | 1–64 字符；首字符为字母或数字，其余可用字母、数字、`.`、`_`、`-` | 整份分发文件与开关的身份。 |
| `name` | 非空字符串，最长 40 字符 | 列表显示名称。 |
| `version` | 整数 ≥ 1 | 合成包版本。 |
| `appliesTo` | **非空**应用包名数组 | 统一应用范围，规则同上。 |
| `entryAfterClick` | 1–64 字符的页面标识 | 用户点击入口后，标识由未出现变为出现才激活内部任务。 |
| `tasks` | 1–8 份完整 `schema: 2` 文档 | 各任务独立识别、动作与复核。 |

子任务 `id` 必须互不重复，且不能与外层 `id` 相同；每个子任务的 `appliesTo` 必须与外层逐项一致。`entryAfterClick` 只在外层声明。未点击入口时，它不启动子任务的持续页面读取；点击后在有限观察窗内确认目标页。页面原本已经显示该标识时，不把路过页面算作一次新进入。新旧用户可以经过不同的中间页，只要最后由用户进入声明的目标页。入口点击门控不代替子任务的页面条件和规则确认。

## 2. when：触发

| 字段 | 类型 | 说明 |
|---|---|---|
| `trigger` | `app-foreground`、`page-foreground`、`page-visit` | 必填。定时器与通知触发未接通。 |
| `windowMs` | 数字 1000–30000 | 从相应进入事件开始的观察窗；省略时默认 12000。 |
| `lifetime` | `window` 或 `foreground` | `foreground` 持续到应用离开前台；此时不能同时写 `windowMs`。 |
| `pagePath` | 1–8 个非空字符串，每项最长 64 字符 | 仅 `page-foreground` / `page-visit` 可用。按页面路径片段匹配，大小写不敏感，不能重复。 |

`app-foreground` 从应用进入前台开始。`page-foreground` 同样依附前台时机，但还要求页面路径命中。`page-visit` 在每次进入新页面时重新开始观察窗；读不到页面路径时不执行。`lifetime: "foreground"` 让任务在前台期间保持可观察，仍受每一步、整轮时长与用户启用状态约束。

## 3. defaults：默认值

| 字段 | 类型与范围 | 默认与继承 |
|---|---|---|
| `limit` | 对象，`maxWidth`、`maxHeight`、`maxArea` 各为 (0, 1] 的窗口比例 | 可被单步 `find.limit` 收紧，不能放宽。实际仍受引擎绝对边界约束。 |
| `settleMs` | 数字 500–15000 | 动作后的复核时限，默认 5000；单步 `expect.settleMs` 优先。 |
| `samples` | 数字 2–4 | 连续匹配的复核帧数，默认 2；单步 `expect.samples` 优先。 |
| `totalMs` | 数字 1000–120000 | 多步整轮时限，默认 30000；从第一步动作发出时计时，`wait` 也计入。 |

`limit` 三项是目标占当前窗口的最大宽度、高度、面积。文档给出更大的数不会放宽轻启的硬边界。若目标过大，应先确认识别到了正确控件。未提供可用尺寸约束的文档会被拒绝。

## 4. steps[]：顺序步骤

普通步骤需要 `find` 和 `do`；`need`、`skipWhen`、`deny`、`expect`、`targetLabel`、`markerEvidenceLabel`、`anchorLabels` 可选。每一步使用自己的词表和判据，前一步未复核成功就停止本轮。步骤计数为 1–8。

| 字段 | 类型 | 作用 |
|---|---|---|
| `find` | 对象 | 目标识别与范围，见第 5 节。 |
| `need` | 对象 | 识别依据和动作前页面条件，见第 6 节。 |
| `skipWhen` | 对象 | 后续可选步骤的跳过条件，见第 8 节。 |
| `deny` | 对象 | 排除语境，见第 6 节。 |
| `do` | 对象 | 动作，见第 7 节。 |
| `expect` | 对象 | 动作后结果，见第 7 节。 |
| `targetLabel` | 非空字符串 | 为识别路径指定目标标签。 |
| `markerEvidenceLabel` | 非空字符串 | 为旁证标记指定标签。 |
| `anchorLabels` | 字符串数组 | 为锚点规则指定标签。 |

`wait` 是特殊步骤：只能写 `{"do":{"capability":"wait","ms":800}}`，不能放在第一步，也不能带其他字段。它只等待，不识别、不发送点击、不产生成功判定。

## 5. find：目标识别

| 字段 | 类型 | 说明 |
|---|---|---|
| `by` | 字符串或非空字符串数组 | `text`（默认）、`desc`、`image`、`structure`；`id` 路径当前未接通。数组中不能重复。 |
| `match` | 非空字符串数组 | 目标允许的文字、描述或标识写法；按字面量处理，正则元字符不会变成通配。 |
| `explicit` | 可选布尔值，默认 `true` | 命中目标是否直接构成明确动作；`false` 时须有额外依据。不能与 `actions` 同时写。 |
| `actions` | 可选字符串数组 | 从 `match` 中选择明确动作文字；不得出现 `match` 之外的值。 |
| `glyph` | 可选非空字符串 | 字形目标，例如关闭图标。 |
| `idHints` | `[[id 词根, 标签], ...]` | 无文字控件可用的完整词根提示；不能把通用词根当唯一依据。 |
| `sameParentText` | 1–8 项非空字符串，每项最长 64 字符 | 目标和任一指定标题必须是同一父节点的直接子节点，适合区分多个“去完成”。 |
| `fold` | `[[原字, 新字], ...]` | 逐项文字折叠。 |
| `normalise` | `[{"pattern":"…","replace":"…"}, ...]` | 按序归一化；非空 `replace` 必须已在 `match` 中。 |
| `limit` | 宽、高、面积比例对象 | 单步几何范围，只能比 `defaults.limit` 更严格。 |

`text`、`desc`、`image` 可组合；`structure` 使用结构识别，还须声明下表字段。选了某条识别路径，却写了该路径不接受的字段，会整份拒绝。`find.by: "id"` 尚未接入；无文字控件可先使用已支持路径的 `idHints`。

### structure 专用字段

| 字段 | 说明 |
|---|---|
| `kinds` | 非空结构名数组，例如 `countdown-image`、`splash-corner`、`ocr-skip`、`ad-corner-image`、`ad-edge-control`、`modal-close`。只能命中引擎实际产出的结构目标。 |
| `label` | 非空目标标签，与规则标签对应。 |
| `semanticKind` | `kinds` 中的一项，标记语义接收者类型。 |
| `adLayerIdGroups`、`containerIdGroups`、`buttonIdGroups` | 非空词组数组；每组为非空字符串数组，组内同时满足、组间满足任一组。`modal-close` 单独使用时可省略广告层与按钮组。 |
| `pagePath`、`countdownWords` | 非空字符串数组；`modal-close` 单独使用时可省略。 |
| `limit` | 同上，结构目标也受几何边界约束。 |

结构字段描述的是“接受哪种由引擎识别出的控件”，不会允许 JSON 把任意坐标或任意 View 宣称为可点目标。

## 6. need 与 deny：依据和页面条件

`need` 可写 `evidence`、`visibleText`、`absentText`：

| 字段 | 类型 | 语义 |
|---|---|---|
| `visibleText` | 1–8 项非空文字，每项最长 64 字符 | 当前可见页面至少包含一项，动作前重查。 |
| `absentText` | 1–8 项非空文字，每项最长 64 字符 | 当前可见页面不得包含任何一项，动作前重查。 |
| `evidence.text`、`evidence.id` | 字符串数组 | 帮助确认目标所属语境，不替代动作前页面条件。 |
| `evidence.cta`、`jump`、`jumpId`、`shake` | 可编译的正则字符串数组，每项最长 200 字符 | 广告落地入口旁证；只用于场景证明，不会变成目标白名单。 |

`cta`、`jump`、`jumpId` 只接受窗口下半部的旁证；`shake` 接受较高位置但需有动作词。`deny.context` 是排除语境字符串数组，与轻启内置排除条件合并，只能收紧。所有声明的页面条件在目标动作前都需重新核对；页面树不可用时，不能把“未看到”当作成功。

## 7. do 与 expect：动作和复核

| `do.capability` | 额外字段 | 说明 |
|---|---|---|
| `click` | 无 | 点击已确认目标。 |
| `back` | 无 | 返回。 |
| `swipe` | 必填 `from`、`to`；可选 `speed` | 坐标均为两个 0–1 数字的窗口比例；`speed` 为 0–10000 数字。 |
| `input` | 必填 `text`，1–64 字符 | 输入文本，结果不得用 `gone`。 |
| `wait` | 必填 `ms`，50–30000 | 仅多步后续步骤可用，见第 4 节。 |

| `expect.result` | 额外字段 | 成功判据 |
|---|---|---|
| `gone`（默认） | 无 | 原目标连续 `samples` 次从新页面读取中消失。 |
| `appeared` | 必填非空 `match` 字符串数组 | 指定文字连续出现。 |
| `text-changed` | 无 | 目标区域文字相对已学习基线变化；基线缺失不能算成功。 |

`expect` 还可写 `settleMs`（500–15000）与 `samples`（2–4），覆盖 `defaults`。`timeout` 尚未接通；时间到了、树读不到、页面变化无法证明，都不等于执行成功。`input` 必须显式配 `appeared` 或 `text-changed`。

## 8. repeat、stopWhen 与 skipWhen

`repeat` 只适用于至少两步、`when.trigger: "app-foreground"` 且 `when.lifetime: "foreground"` 的流程：

| 字段 | 类型与范围 | 作用 |
|---|---|---|
| `maxCycles` | 必填整数 2–10 | 最多完整重复轮数。 |
| `cooldownMs` | 必填整数 500–10000 | 一轮成功后再观察的短冷却。 |
| `idleMs` | 必填整数 3000–30000 | 目标暂未出现时的观察上限。 |
| `stopWhen` | 可选 `{"text":"状态","nearText":"当前卡片标题"}` | 在下一轮开始前核对当前卡片的状态；两项各 1–64 字符。 |

`stopWhen` 需要状态与卡片标题是同一父容器的直接子节点。当前卡片显示“已领取”时即可结束该子任务并继续其他子任务，避免等待完整 `idleMs`。页面信息不明确时，仍按有界观察与复核处理。

`steps[].skipWhen` 适用于多步流程的**后续**步骤。`visibleText` 和 `absentText` 都必填、各为 1–8 项非空文字（每项最长 64 字符）；前者要求全部指定标识可见，后者要求全部指定标识不可见。条件须在两次新页面读取中连续成立才跳过这一步。`stopRepeat` 可选布尔值；为 `true` 时只能写在最后一步，同时结束当前任务的重复。它适合“前两步完成后，奖励弹窗因领奖上限没有出现”这类可选末步，不会把缺失弹窗判作已领奖。

## 9. 优先级、启用和分发语义

导入只是保存配置。应用须启用，规则须经用户确认；每次动作前还检查当前前台、目标唯一性、可见可用状态、尺寸、上下文与包归属。多个包可同时启用；合成包对外只有一个开关，内部子任务按各自 `priority` 参与调度。相同优先级由引擎的稳定顺序处理，不能靠文件里的数组顺序表达强制流程。

步骤之间通过“前一步成功判据”连接；独立子任务之间应靠各自的页面条件与优先级配合。需要下滑才能看到的任务，可把下滑设为单独子任务：当前锚点可见、下一标题不可见才滑，`expect.result: "appeared"` 复核下一标题出现。这样屏幕高度变化时不会按固定行号误点。

## 10. manual：用户示范入口

`manual` 目前只支持 `{"capability":"layout-tap","title":"…","instruction":"…"}`，并且 `when.trigger` 必须是 `app-foreground`。`title` 为 1–24 字符，`instruction` 为 1–120 字符，均不能只含空白。它让用户主动发起页面布局点击示范，不是后台自动点击的替代触发。

## 11. 常见拒绝原因

| 配置 | 原因 |
|---|---|
| 写 `find.by: "id"` | 该识别路径当前未接入。 |
| 没有 `defaults.limit` 且步骤也无 `find.limit` | 缺少可解析的几何边界。 |
| `find.limit` 大于 `defaults.limit` | 步骤只可收紧，不能放宽。 |
| `swipe` 缺 `from` 或 `to` | 坐标必须是窗口比例对。 |
| `input` 不写 `expect` 或写 `gone` | 输入框不会因为输入而消失。 |
| `repeat` 配短观察窗或单步 | 重复只支持前台期间的多步流程。 |
| `skipWhen` 配第一步，或末步外写 `stopRepeat: true` | 跳过条件只适用于指定的后续位置。 |
| 合成包子任务应用数组与外层不同 | 一份开关不能扩大或改变应用范围。 |
| 字段拼错、把未实现能力写进包 | 为避免静默失效，整份配置被拒绝。 |

校验命令见 [制作教程](TOOL_PACKS.md#7-校验导入更新)。字段更新以实际轻启版本的导入校验结果为准。
