# 开屏广告工具包（轻启 1.1.0）

**[获取 V5 工具包 JSON](splash-ad-v5.task.json)**

这份工具包使用轻启 1.1.0 支持的 `schema: 2` 格式。它识别常见的“跳过”“关闭广告”、带倒计时的按钮，以及有足够页面线索的图片控件；应用进入前台后的观察窗口为 12 秒。配置包含 1.1.0 支持的页面边缘控件识别和“扭一扭”广告线索。

## 导入

1. 在上面的 JSON 页面复制全文，或把文件保存到手机。
2. 打开轻启 →「工具包」→「导入工具包」，粘贴 JSON 或选择保存的文件。导入后确认工具包处于启用状态。
3. 在轻启中选择要执行的应用。首次识别后，如果未开启「规则自动启用」，到「规则」页确认新规则。

工具包 `id` 与旧版相同；导入 V5 会更新已有的 V3/V4 开屏广告工具包。它只定义识别条件，实际点击仍以应用和规则的启用状态为准。
