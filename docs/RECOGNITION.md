# 广告识别方式

规则上显示的 S01～S08 是首次学习的主要依据。点击编号可查看同一策略的示例、确认依据、点击目标与放弃条件；已补充样式的规则还会显示当时的控件组成。一个按钮可以同时有广告标记、文字计时和进度环，辅助依据单独记录。

| 编号 | 名称 | 主要依据 |
| --- | --- | --- |
| S01 | 明确广告操作 | “跳过广告”等明确操作文字 |
| S02 | 按钮与广告标记 | 关闭目标与广告标记或广告图层 |
| S03 | 文字倒计时 | 关闭目标与同组或相邻的文字计时 |
| S04 | 图形倒计时 | 关闭目标与相关进度控件 |
| S05 | 图标语义 | 描述、控件标识中的关闭含义及广告依据 |
| S06 | 广告容器结构 | 已支持的容器、图片、计时和关闭目标关系 |
| S07 | 图片文字兜底 | 对已找到的候选，用 OCR 补充图片内广告标记 |
| S08 | 用户示范确认 | 主动学习中的用户点击与后续消失确认 |

## 示意与实际点击

手机轮廓保留屏幕比例，闪动标记指向目标位置；小目标适当放大。外侧样例按控件坐标排列文字、数字、图片与进度控件，支持左右分离、上下排列和圆环内文字。默认不把 `3s｜跳过` 改写为 `跳过 3s`。

外形分矩形、圆角矩形、胶囊、椭圆、圆形和无边框。控件未提供明确外形属性时，数据保持未知，**默认用圆角矩形绘制**。正方形边界不作为圆形的证据；同组的 Progress 圆环或包围关闭文字的 Circle 轮廓优先显示为圆形。Circle 只证明外形，不会单独成为广告倒计时依据。示意采用统一主题配色，不复刻广告素材。未读取到内容的图片显示简化图标，不能据此推断原图片的精确形状。

文字节点、实际接收点击的父容器、相关图片和进度控件分别记录。示意与点击范围分开：手机标记以可见按钮为准，放大背景完整包住同组文字和数字；手机内淡色边界来自已读取的容器和图片范围。背景始终保留两条浅色骨架线，仅用于页面示意，不代表实际读取的文字。旧规则没有图层字段时仍保留骨架，后续正常学习观察会补充图层，不要求清空规则。

横排文字的放大示意压缩控件上下空白，保留数字与文字的位置顺序，避免绘成过厚的按钮。圆形、椭圆、进度环及上下排列的内容保持等比缩放；手机内的位置标记和实际点击范围不受此排版调整影响。

## 识别和执行

已有启用规则优先匹配应用、实时按钮、位置、类型及状态；核对遮挡后点击，不重新要求广告 OCR。有关闭语义的容器如果只有一个可点击图片子控件，落点取该实时子控件中心，规则仍按原容器身份匹配；遮挡检查和第二帧复核使用该落点。未匹配的样式才进入新规则识别。自动学习规则按设置等待确认或自动启用；主动学习仍需对应点击事件并确认目标消失。

策略编号、外形、计时数字、主题配色均不参与规则键计算。数字递减不会生成另一条规则，展示数据损坏也不会丢弃有效规则及其启用状态。纯数字计时不自动证明可以关闭；`7x24` 等频道名、乘法或尺寸文字不能作为叉号操作。

## 维护

- `RecognitionProfile.ets` 是策略编号、说明及数据类型的共同定义；已有编号不随界面排序变化。
- `ProfileCapture.ets` 从已读取的控件树提取必要样式和证据，不额外截图、执行 OCR 或获取控件。
- `LearningStore.ets` 保存可选 profile；规则键、审批及删除代次沿用原逻辑。
- `ButtonPreviewLayout.ets` 对按钮与内容使用同一个坐标变换；`ButtonSample.ets` 同时用于规则卡片和策略页。

样式信息不授予点击权限。新策略需要对应的正常场景和拒绝场景测试；真实样本回放不能替代真机点击、耗时和耗电验证。
