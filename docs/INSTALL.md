# 侧载安装指南

安装完成后的流程是：**一个主 HAP → 手机向导 → 本机连接 → 自动准备工作模块 → 在线 → 确认广告规则**。

本文介绍通过官方 hdc 安装调试签名包。轻启内置 UiTest 工作模块，用户不需要下载或手动安装第二个 HAP；首次授权后由轻启自行完成。

## 1. 准备设备和安装包

需要一台支持开发者模式、USB 调试和无线调试的 HarmonyOS 手机、一台电脑、可传输数据的 USB 线，以及官方 DevEco Studio / HarmonyOS SDK 中的 hdc 工具。手机本机连接时需按系统要求连接 Wi-Fi。

当前真机验证范围为 Pura X / HarmonyOS 7（API 26）。其他机型及系统版本请先验证无线调试是否可用。

| 你已有的文件 | 下一步 |
| --- | --- |
| 为你这台手机签名的交付 ZIP | 解压，确认包含 `entry-default-signed.hap`、安装脚本和说明，进入第 2 步 |
| 项目源码或源码 ZIP | 先按第 2 步连接手机，再按第 3 步签名构建 |
| 作者为自己的手机签名的 HAP | 按[内外包重签教程](RESIGN.md)换成自己的设备授权签名；也可从源码签名构建，或由提供者将你的设备纳入调试授权后重新构建 |
| AGC 用的 `.app` | 不按本文侧载；它是平台上传文件，本项目尚未验证邀请分发后的完整链路 |

**签名需覆盖目标设备且在有效期内。只重签主包不够：内置模块也必须使用匹配签名。** 可以通过项目构建脚本一起生成，或按[重签教程](RESIGN.md)处理已有主 HAP。不需要向任何人提供华为账号密码或签名私钥。设备调试授权以开发者平台配置为准，见 [华为自动签名说明](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/ide-signing-auto)。

## 2. 开启开发者模式并连接电脑

1. 手机进入“设置 → 关于本机”（部分版本显示具体设备名称），连续点击“软件版本”七次。
2. 按系统提示确认开启，输入锁屏密码；如提示重启，等待重启并解锁。
3. 进入“设置 → 系统 → 开发者选项”，开启 USB 调试；也可在设置中搜索“开发者选项”。
4. 用数据线连接电脑，保持手机解锁，在手机提示中允许这台电脑调试。
5. 用官方 hdc 查看设备；正常结果应列出一个设备 ID，不能是 `[Empty]`。

系统菜单以实际版本为准，参见 [华为开发者模式说明](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/ide-developer-mode)。

macOS 终端（DevEco Studio 默认安装位置）：

```sh
export HDC_BIN="/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc"
"$HDC_BIN" list targets
```

Windows **命令提示符 CMD**（将路径替换为自己的官方 SDK 路径）：

```bat
set "HDC_BIN=C:\你的SDK目录\openharmony\toolchains\hdc.exe"
"%HDC_BIN%" list targets
```

若找不到 hdc，在 DevEco Studio 的 SDK 设置中确认实际 SDK 目录，并找到 `openharmony/toolchains/hdc`（Windows 为 `hdc.exe`）。安装脚本不附带 SDK 工具。下面的安装步骤请只连接一台目标手机，并断开额外的电脑无线调试连接。

## 3. 从源码生成自己的安装包

已有针对自己设备构建的完整主 HAP，可直接进入第 4 步。

以下构建流程已在 **macOS Apple Silicon / DevEco Studio 26.0.0 / SDK 26** 使用。Windows 安装已签名包的命令见下一节；当前自动构建脚本使用 macOS SDK 目录，未提供经过验证的 Windows 源码构建脚本。

1. 解压源码，在项目根目录打开终端；该目录应有 `AppScope`、`entry` 和 `scripts`。
2. 创建本机配置，再用 DevEco Studio 打开该目录并同步项目依赖：

   ```sh
   test -f build-profile.json5 || cp build-profile.example.json5 build-profile.json5
   ```

3. 保持手机已连接且授权。打开 DevEco Studio 的 `File → Project Structure → Project → Signing Configs`，按官方自动签名流程登录自己的华为开发者账号，为这台设备生成调试签名。不同 IDE 版本的菜单名称可能略有差异。
4. 确认项目的 `default` 产品使用已配置的签名。在项目根目录执行：

   ```sh
   bash scripts/build.sh
   ```

5. 等待构建成功及 `Single-package verified` 提示。唯一需要安装的文件为：

   ```text
   entry/build/default/outputs/default/entry-default-signed.hap
   ```

**不要只点击 IDE 的主模块 Build/Run 来代替第 4 步。** 项目脚本先构建工作模块，再将它嵌入主包；单独构建主模块可能遗漏资源或使用旧模块。不要修改包名来解决签名问题，当前本机启动逻辑使用项目固定包名。

构建失败请看 [构建说明](BUILD.md)。源码不包含作者的签名、已签名 HAP 或 hdc。

## 4. 只安装轻启主包

有交付 ZIP：解压后进入该目录，脚本和 `entry-default-signed.hap` 应在同一层。

macOS：

```sh
bash install-to-user-device.sh
```

Windows CMD：

```bat
install-to-user-device.bat
```

请在当前终端中先设置第 2 步的 `HDC_BIN`。脚本会要求只连接一台设备，安装主 HAP，并检查系统安装成功提示。

从源码构建的用户可直接在项目根目录执行：

```sh
"$HDC_BIN" install -r entry/build/default/outputs/default/entry-default-signed.hap
```

成功输出应包含 `install bundle successfully`。随后在手机桌面打开轻启。**不要安装 `entry-ohosTest-signed.hap`，也不要运行电脑端激活脚本。** 这些不属于普通用户首次安装流程。

## 5. 在手机完成本机激活

1. 在手机开启 Wi-Fi，并进入“开发者选项 → 无线调试”，按系统提示开启。
2. 记下无线调试页面当前显示的端口号，例如 `41907`；示例不能照填。轻启只填端口，不填电脑 IP、服务器地址或配对码。
3. 打开轻启，按首次向导操作，或进入“概览 → 本机连接”，输入该端口并点击连接。
4. 手机出现调试授权提示时，核对后允许“轻启本机激活”。首次连接会显示正在准备、安装工作模块，期间保持手机解锁及轻启在前台。
5. 等待应用重新打开，确认概览显示 **“在线”**。只有出现新会话心跳才算连接成功；“正在安装”或“命令已发送”不代表已就绪。
6. 拔掉 USB，正常打开一个应用触发开屏广告，再返回轻启查看运行记录，确认本机独立运行。

UiTest 工作模块来自轻启主包，不从外网下载。日常运行无需电脑一直连接；保持无线调试可用。重启、端口改变或系统结束会话后，重新按本节连接即可，不需要再次侧载主包。

## 6. 确认并启用规则

1. 在设置中确认“自动发现应用”和“学习新规则”开启。
2. 正常打开其他应用，触发开屏广告。
3. 返回轻启“规则 → 待确认”，检查按钮文字与位置，确认后启用。
4. 确认该应用及自动跳过总开关已开启，再次遇到匹配广告时观察运行记录。

没有现成规则时，首次广告可能只用于学习；不是安装失败。同一应用的新样式仍需单独确认，不能仅凭有一个关闭按钮就判断为广告。

## 升级与卸载

升级：用相同签名、相同包名的新主 HAP 覆盖安装，通常保留规则和设置；重新本机连接后，轻启会检查并准备匹配版本的内置模块。不要混用不同来源或不同签名的安装包。

卸载：先停止轻启会话，再按系统方式卸载轻启。规则和配置会随应用数据删除；日常升级无需卸载。无需使用无线调试时可关闭它。

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| hdc 找不到或 `[Empty]` | 核对工具路径、数据线、USB 调试；解锁并允许电脑授权 |
| 多个连接目标 | 断开其他手机或电脑的额外无线调试连接，确保列表只剩一项 |
| 主包安装被拒绝 | 检查签名有效期、设备授权和包类型；不要用 AGC `.app` 或作者的个人调试包直接侧载 |
| 提示签名不一致 | 用原签名重新构建；若决定换签名，需要先自行确认数据可丢失，再卸载旧版 |
| 缺少工作模块或校验失败 | 按 `scripts/build.sh` 重新生成完整主包；不要手动塞入测试 HAP |
| 工作模块安装失败 | 查看轻启显示的完整错误；核对主包和模块是否同次、同签名构建及设备是否在授权范围内 |
| 一直连接中或离线 | 检查无线调试、当前端口、系统授权及手机解锁状态，回到轻启重试；失败不等于需要手动安装 UiTest |
| 在线但不跳过 | 检查规则是否已确认启用、应用和总开关，再看运行记录具体原因 |
