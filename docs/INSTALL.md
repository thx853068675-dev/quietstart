# 轻启 1.1.0 安装说明

已有小白轻启整合助手的用户，只需下载 `quietstart-1.1.0.hap`。首次使用可下载对应电脑的完整整合包，内含助手、HAP和本说明；Mac适用于Apple芯片，Windows适用于x64。Release 附件不含工具包；需要自定义识别场景时可参考[工具包制作教程](TOOL_PACKS.md)。

## 电脑安装或升级

1. 解压整个整合包。Windows保留EXE旁的DLL和data目录；Mac可将APP移到“应用程序”。
2. 手机进入“设置 → 关于本机”，连续点击软件版本开启开发者模式，按系统提示重启；已开启可跳过。进入开发者选项，开启USB调试。
3. 用USB连接手机，在手机上允许调试；打开整合助手，登录自己的华为开发者账号并连接手机。
4. 点击“选择HAP”或“更换版本”，选中 `quietstart-1.1.0.hap`，确认界面显示1.1.0。助手不自动预选版本。
5. 点击“开始调试”，等待签名和安装完成。请使用支持轻启内外一起重签的整合版，不要只给主包重签；不需要安装DevEco、SDK、Java或运行脚本。
6. 打开手机上的轻启，按向导开启无线调试，填写当前端口并允许授权，等待概览显示在线。
7. 默认的“后台保护 · 计算任务”无需定位权限；模拟定位仍可作为可选方式。确认后台保护状态和系统持续任务通知。
8. 在线后可拔掉USB，正常打开其他应用。轻启可通过用户自制的工具包扩展具体场景；按[制作教程](TOOL_PACKS.md)写好 JSON 后，用明文 JSON/TXT 文件或粘贴导入，再选择执行应用。开启“规则自动启用”时新规则直接启用，否则在规则页确认；可随时停用或删除单条规则。

## 手机本机更新：小白·轻启

手机端助手使用独立包名，可与原版小白同时安装。版本仍为3.1.1，本次无需重复安装。

首次安装助手：下载 `xiaobai-quietstart-3.1.1-unsigned.hap`，先用电脑签名工具为自己的手机授权并安装。它是未签名包，不能直接点开安装。若使用本整合助手，其首页只接受轻启主HAP；手机端助手的首次安装应使用支持普通HAP的原版小白桌面工具或其他正规侧载签名工具。

助手已经安装后：

1. 下载 `quietstart-1.1.0.hap` 到手机。
2. 打开“小白·轻启”，登录自己的华为开发者账号；开启本机无线调试并连接当前端口，允许系统弹出的调试授权。
3. 选择轻启HAP，点击“开始调试”，等待重签与安装完成。
4. 打开轻启，重新完成本机连接并确认后台运行保护状态。

## 常见情况

- 所有HAP都需要适用于自己设备的签名授权。电脑或手机助手登录及申请签名材料需要联网；不要直接把作者签名当作任意手机可安装的签名。
- 同一有效签名通常可以覆盖升级并保留规则。提示签名不一致时先处理签名材料，不要直接卸载；卸载会删除应用数据。
- 重置证书或Profile后，使用整合助手重新处理轻启主HAP，让内外模块一起重签。
- 无线调试端口变化时，以系统当前显示为准。提示Unauthorized时需在手机允许调试，不能仅凭连接提示判断已授权。
- Mac提示无法验证开发者：该修改版未经Apple公证；确认来源后可使用“隐私与安全性 → 仍要打开”，不要关闭系统整体安全保护。
- 本次桌面助手程序沿用 1.0.0，整合包更新了HAP与说明；Mac/Windows整合包未在本轮重新做安装测试。
