# 源码发布

只发布轻启独立源码，勿上传包含其他项目的父目录。源码包与设备签名安装包分开管理。

## 导出

```sh
python3 tools/run-tests.py
python3 tools/export-source.py
```

输出 `dist/quietstart-source-<版本号>.zip`。导出器只选择项目源码、构建工具、测试及公开文档，排除本机签名配置、证书、私钥、设备产物、缓存、原始社区快照和 AGC 提审材料。发现疑似凭据或个人绝对路径时停止导出。

## 检查后发布

1. 将 ZIP 解压到独立目录；不要直接推送当前父目录仓库。
2. 阅读 README、安装指南、MIT 许可和第三方声明，确认没有私有材料；保留第三方来源清单。
3. 从解压后的目录运行离线回归，配置自己的签名后按安装指南构建。
4. 自行发布到选定的开源仓库；导出工具不创建或推送远程仓库。

运行时 UiTest 代码是应用功能依赖，必须保留；排除的是构建出的已签名模块和本机数据。AGC 包解析、离线测试、真机安装、拔线运行分别报告，不互相替代。

安装 ZIP 的生成方式见 [构建说明](BUILD.md)，接收者的完整流程见 [侧载安装指南](INSTALL.md)。

## 安装工具

小白轻启整合版的源码、Mac / Windows 构建和发布现已独立迁至 [quietstart-installer](https://github.com/thx853068675-dev/quietstart-installer)。本仓库只维护轻启应用及其构建、侧载脚本。

正式版显示版本统一为 `0.9.55`。内部 `versionCode` 使用 `96001`，高于之前本地 `0.9.60-test / 96000` 实验包，允许测试用户保留数据覆盖升级。主包与工作模块必须一致；后续构建代码继续递增，不从显示版本反推。0.9.54～0.9.60-test 的文档编号保留为历史测试记录。
