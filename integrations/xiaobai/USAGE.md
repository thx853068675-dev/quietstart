# 轻启整合安装包

此包包含修改后的小白调试助手和轻启 0.9.43。整合版由轻启维护者制作，基于小白调试助手，不是小白官方发布版。

## 第一次安装

1. 解压整个压缩包。Mac 版适用于 Apple 芯片；Windows 版适用于 x64。
2. 打开包内调试助手。Windows 请保留 EXE 旁的 DLL 和 data 文件夹；Mac 可将 APP 拖入“应用程序”。
3. 在手机“设置 → 关于本机”连续点击版本号开启开发者模式，再进入开发者选项开启 USB 调试。用数据线连接电脑，在手机上允许调试。
4. 在助手中登录你自己的华为账号，连接你的手机，点击“选择内置轻启 0.9.43”。
5. 点击“开始调试”。助手申请这台手机的授权 Profile，自动重签工作模块、更新摘要、重签主包，最后安装轻启。
6. 手机打开轻启，按照向导开启无线调试并填写当前端口，完成本机连接。工作模块由轻启自动安装，不需要再次选择文件或手动导入。
7. 显示在线后拔掉 USB，按轻启向导继续配置。

不需要安装 DevEco Studio、HarmonyOS SDK、Java、Python，也不需要运行重签脚本。电脑联网用于账号登录和申请签名材料；不能使用维护者的签名直接给任意手机安装。

## 常见情况

- 签名材料失效：使用助手的重置证书与 Profile 功能，再执行“开始调试”，内外模块会一起重新签名。
- 已有同包名应用但签名不同：先确认需要保留的数据；卸载会删除本机数据。此整合流程不会替你自动卸载旧应用。
- Mac 系统提示无法验证开发者：这是未公证的修改版。确认来源后使用系统“隐私与安全性”的“仍要打开”。不要关闭系统整体安全保护。
- 本机连接端口变化：以手机无线调试页面当前端口为准。
- Windows 的签名/安装结果以设备返回为准；构建成功不等同于真机验证成功。

## 包内的 HAP

HAP 同时嵌入助手，点击按钮即可选择。单独附带的 `quietstart-0.9.43.hap` 方便备份，内容相同；不要用未适配的普通重签流程只签外包。
