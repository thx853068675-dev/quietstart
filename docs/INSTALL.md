# 轻启安装与升级说明

## 手机端安装（推荐）

**一台手机即可完成侧载，无需电脑，也无需先自行签装安装器。**

1. 打开[轻启·安装器邀测链接](https://appgallery.huawei.com/link/invite-test-wap?taskId=228570a673362a352b80bb8db6992c85&invitationCode=4ZtxqMmENjl)，通过华为应用市场安装轻启·安装器。
2. 按安装器引导完成账号和设备授权，开启所需开发者选项、无线调试并建立本机连接。
3. 在安装器中选择轻启，为本机签名并安装。如需指定版本或 Beta，先从对应 [Release](https://github.com/thx853068675-dev/quietstart/releases) 下载轻启 HAP，再在安装器中从本地导入并安装。
4. 打开轻启，按向导完成本机连接，确认概览显示“在线”，并检查后台保护状态。
5. 在“工具包”中导入并启用需要的兼容工具包，在“应用”中开启对应应用。本项目不随正式版提供具体工具包附件。

原“小白·轻启”已弃用。Release 中的无签名安装器 HAP 仍可作为备用附件，需要自行签名后安装；从邀测链接安装无需此步骤。轻启 HAP 也不是可跨设备直接安装的通用签名包。

## 电脑安装或升级（备用）

以下步骤适用于提供整合包的版本，例如 1.2.0 正式版。已有桌面整合助手的用户可从[最新 Release](https://github.com/thx853068675-dev/quietstart/releases/latest) 下载独立的轻启 HAP；首次使用可下载对应电脑的完整整合包，Mac 选 Apple 芯片版，Windows 选 x64 版。

1. 解压整个整合包。Windows 保留 EXE 旁的 DLL 和 data 目录；Mac 可将 APP 移到“应用程序”。
2. 手机开启开发者模式和 USB 调试，用 USB 连接电脑并允许调试授权。
3. 打开整合助手，登录自己的华为开发者账号，选择所下载的轻启 HAP，核对显示版本与 Release 一致。
4. 点击“开始调试”，由助手为手机重签轻启主包和内嵌工作模块，等待安装完成。需要同时重签内外两层。
5. 打开轻启，按向导开启无线调试、填写当前端口并允许本机连接。概览显示在线后检查后台保护状态。
6. 在“工具包”中导入并启用需要的兼容工具包，在“应用”中开启对应应用。本项目不随正式版提供具体工具包附件。

轻启默认使用计算任务后台保护；这条路径无需定位权限。计算任务能否获授权由手机系统和重签材料决定。

## 使用提示

- 示范学习需要工具包声明相应能力；已有 V4 工具包的普通识别可继续使用，页面布局示范需要 V5 或更新的兼容包。示范生成的有效规则可在应用自动执行列表查看和管理。
- 新规则自动启用默认开启；已有明确停用设置会保留。仍需用户确认的规则不会因此自动执行。
- 隐藏后台默认关闭。隐藏多任务卡片不能保证绕过系统一键清理；需要时保留卡片并使用系统提供的加锁方式。
- 普通纯绘制页面默认不做探索性截图 OCR。应用详情可以关闭该应用全部截图 OCR，也可以按需开启“探索纯绘制页面”。关闭 OCR 会减少截图分享干扰，同时限制图片文字识别；开启探索仍可能触发应用的截图分享。
- 可添加 2×2 桌面状态卡片，查看连接状态与执行指标。

## 升级与校验

同一有效签名下覆盖安装通常保留规则、工具包和设置。提示签名不一致时应检查签名材料，卸载会删除应用数据。

下载后核对 Release 提供的 SHA-256 校验值。桌面助手的原项目：<https://github.com/likuai2010/auto-installer>；整合版由轻启维护者修改，不是小白官方版。
