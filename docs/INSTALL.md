# 轻启安装与升级说明

已有桌面整合助手的用户可从[最新 Release](https://github.com/thx853068675-dev/quietstart/releases/latest) 下载独立的轻启 HAP。首次使用可下载对应电脑的完整整合包；Mac 选 Apple 芯片版，Windows 选 x64 版。

## 电脑安装或升级

1. 解压整个整合包。Windows 保留 EXE 旁的 DLL 和 data 目录；Mac 可将 APP 移到“应用程序”。
2. 手机开启开发者模式和 USB 调试，用 USB 连接电脑并允许调试授权。
3. 打开整合助手，登录自己的华为开发者账号，选择所下载的轻启 HAP，核对显示版本与 Release 一致。
4. 点击“开始调试”，由助手为手机重签轻启主包和内嵌工作模块，等待安装完成。需要同时重签内外两层。
5. 打开轻启，按向导开启无线调试、填写当前端口并允许本机连接。概览显示在线后检查后台保护状态。
6. 在“工具包”中导入并启用需要的兼容工具包，在“应用”中开启对应应用。本项目不随正式版提供具体工具包附件。

轻启默认使用计算任务后台保护；这条路径无需定位权限。计算任务能否获授权由手机系统和重签材料决定。

## 手机端安装

从[最新 Release](https://github.com/thx853068675-dev/quietstart/releases/latest) 下载轻启·安装器的正式无签名 HAP，并核对发布页提供的 SHA-256 校验值。如果同时提供预览版，一般选择正式版。

无签名 HAP 不能直接安装。先使用自己的开发者身份为目标设备签名并侧载安装器，再打开安装器选择轻启完成安装。

安装完成后打开轻启，按向导完成本机连接，并确认概览显示“在线”。原“小白·轻启”已弃用。

## 使用提示

- 示范学习需要工具包声明相应能力；已有 V4 工具包的普通识别可继续使用，页面布局示范需要 V5 或更新的兼容包。示范生成的有效规则可在应用自动执行列表查看和管理。
- 新规则自动启用默认开启；已有明确停用设置会保留。仍需用户确认的规则不会因此自动执行。
- 隐藏后台默认关闭。隐藏多任务卡片不能保证绕过系统一键清理；需要时保留卡片并使用系统提供的加锁方式。
- 普通纯绘制页面默认不做无广告线索的探索性截图 OCR。应用详情可以关闭该应用全部截图 OCR，也可以按需开启“探索纯绘制页面”。关闭 OCR 会减少截图分享干扰，同时限制图片文字识别；开启探索仍可能触发应用的截图分享。
- 可添加 2×2 桌面状态卡片，查看连接状态与执行指标。

## 升级与校验

同一有效签名下覆盖安装通常保留规则、工具包和设置。提示签名不一致时应检查签名材料，卸载会删除应用数据。

下载后核对 Release 提供的 SHA-256 校验值。桌面助手的原项目：<https://github.com/likuai2010/auto-installer>；整合版由轻启维护者修改，不是小白官方版。
